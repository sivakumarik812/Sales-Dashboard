# 📊 Sales Dashboard

An end-to-end Data Analytics project analyzing sales performance using Python, SQL, and Power BI. This project demonstrates synthetic data generation, ETL pipelines, SQL aggregation queries for business insights, and interactive dashboard visuals.

---

## 🛠️ Tech Stack & Tools
* **Programming:** Python (Pandas, NumPy)
* **Database & Querying:** SQL (PLSQL)
* **Data Visualization:** Power BI Desktop
* **Version Control:** Git & GitHub
